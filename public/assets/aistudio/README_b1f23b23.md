# AgroResiliente Inhambane

**Site:** https://agroresiliente.co.mz

Plataforma digital para pequenos e médios produtores familiares em Homoíne, Inhambane, Moçambique.

Canais: USSD (*123#), SMS (123), web e app/PWA.

## Demonstração local

```bash
cd agroresiliente
python3 -m http.server 8080
```

Abrir http://localhost:8080

## Funcionalidades da demo

- Cadastro e login de produtores (localStorage)
- Área Minha Conta
- Simulador USSD interactivo (12 culturas, 4 mercados)
- Simulador SMS (PRECO, ALERTA, DICA, AJUDA)
